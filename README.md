# gitutils
Collection of git scripts and useful configs.

# Usage

Inside your git config (`git config --global -e`):

```
[alias]
    reprune = !/path/to/repo/scripts/reprune
    savepoint = !/path/to/repo/scripts/savepoint
    undo = !/path/to/repo/scripts/undo
    vlog = !/path/to/repo/scripts/vlog
    yeet = !/path/to/repo/scripts/yeet
```
